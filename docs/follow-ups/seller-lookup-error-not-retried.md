# 판매처 가격 조회 실패가 다시 시도되지 않음

- **증상:** 숙소의 판매처 가격 미리 조회가 한 번 실패하면, 그 숙소는 카드와 상세 패널 모두 실패 상태로 남는다. 같은 검색 화면에서는 다시 조회하지 않는다.
- **근거:** `features/lodging/use-seller-prefetch.ts`는 숙소 id마다 결과를 한 번만 저장하고, 한 번 대기열에 넣은 id는 다시 넣지 않는다(`run-limited.ts`의 `seen`). 2026-10-29 숙소 구현 코드 리뷰(low)에서 처음 지적됐고, 미리 조회로 바꾼 뒤에도 그대로다.
- **영향:** 수용 기준 9(실패 시 예약 사이트 링크 제공)는 지켜진다. 일시적인 실패 뒤에 사용자가 다시 시도할 방법이 없다는 불편만 있다.
- **제안:** 상세 패널의 실패 상태에 "다시 시도" 버튼을 두고, 누르면 그 id를 대기열에 다시 넣는다.
