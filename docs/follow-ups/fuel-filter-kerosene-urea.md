# 주유소 연료 필터에 등유·요소수가 없음

- **증상:** 주유소 탭의 연료 필터는 휘발유·경유·LPG만 고를 수 있다. 사용자가 요청한 등유와 요소수는 거를 수 없다.
- **근거:** 연료 정보는 카카오맵 검색 결과(`features/nearby/kakao.ts`)에서 가져오는데, 가격 필드는 `oil1`–`oil4`(휘발유·고급휘발유·경유·LPG)뿐이고 등유 필드는 없다. `yososu_info`(요소수) 필드는 있지만 2026-10-31에 강서구·강릉시 주유소 수십 곳을 조회해 보니 모두 `null`이었다.
- **영향:** 등유를 파는 주유소나 요소수를 파는 주유소는 찾을 수 없다. 나머지 연료 필터는 정상 동작한다.
- **제안:** 한국석유공사 오피넷 API(실내등유 가격 제공)의 키를 발급받아 주유소별 등유 판매 여부를 보강한다. 요소수는 오피넷에도 없을 수 있어 별도 소스를 먼저 찾아야 한다.
