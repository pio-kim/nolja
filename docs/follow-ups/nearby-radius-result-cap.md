# 주변 장소 반경을 넓혀도 결과 수가 늘지 않음

- **증상:** 주변 장소 탭에서 반경을 3km에서 10km로 넓히면 더 먼 곳까지 나오지만, 목록 개수는 그대로다(강릉중앙시장 주유소 기준 3km·10km 모두 22곳).
- **근거:** Google Places Nearby Search(`features/nearby/server.ts`)는 요청당 최대 20곳만 주고 페이지를 넘길 수 없다. 넓은 반경에서는 인기순 상위 20곳만 남고, 네이버 보강은 키워드마다 5곳이다.
- **영향:** 10km에서 거리순으로 보면 가까운 곳 일부가 빠질 수 있다. 반경 선택 자체는 동작한다.
- **제안:** 넓은 반경에서는 원을 몇 개로 나눠 여러 번 조회하고 합치거나, Text Search(최대 60곳, 페이지 지원)로 바꾸는 것을 검토한다.
